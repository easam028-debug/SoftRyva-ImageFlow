# Security policy (draft for review)

No public security disclosure channel has been configured yet. **Do not publish a URL
or claim private vulnerability reporting is enabled** until the public GitHub repository
exists and its security settings are configured. Do not post confidential vulnerabilities
or credentials in public issues. Release maintainers should enable GitHub private
vulnerability reporting before requesting SignPath consideration.

The application processes local images; care is still required with untrusted image inputs,
image-library security updates, bundled binaries, and Windows installer behavior.
