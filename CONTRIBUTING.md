# Contributing to SoftRyva ImageFlow

This repository is **not public yet**. Until it is approved for release, do not share
working copies containing private assets or credentials.

- Open a GitHub issue before large feature changes after publication.
- Run `python -m unittest discover -s tests -q` before proposing changes.
- Include tests for new image transformations; do not overwrite originals.
- Keep user images local. Do not add telemetry or network features without explicit review.
- Respect the selected `GPL-3.0-only` license. Submit only code you have rights to contribute.
- Contributors keep their own copyrights. Contributions must be compatible with GPL-3.0-only;
  add SPDX and copyright information where needed.
- Do not commit GPG private keys, API tokens, personal documents or user image samples.
- All release builds require review before signing and publication.
