# SoftRyva ImageFlow V0.3.1 — جاهز لبناء Setup

**هذه حزمة الشيفرة مع أدوات بناء Setup، وليست ملف Setup.exe مجمّعًا.**

التعديل المطلوب: تم تكبير شريط التمرير العمودي إلى 24 بكسل على الأقل، ويزداد على شاشات DPI المرتفع. يسري على Optimize وSettings وImage Resizer وHistory.

## إنشاء Setup على Windows

1. فك ضغط ZIP في مجلد جديد.
2. ثبّت Python 3.10 أو أحدث وInno Setup 6.6 أو أحدث من موقعهما الرسمي.
3. اضغط مرتين على `BUILD_SETUP_WINDOWS.bat` وانتظر نتيجة الاختبارات والبناء. يجب توفر الإنترنت لتحميل أدوات البناء أول مرة.
4. تجد ملف التثبيت في `dist_setup\SoftRyva_ImageFlow_Setup_v0.3.1.exe` وملف SHA256.txt.
5. اختبر Setup ثم البرنامج المثبّت وتحديث نسخة سابقة وإزالة التثبيت قبل النشر الرسمي.

يمكنك أيضًا تشغيل الشيفرة مباشرة عبر `START_WINDOWS.bat`، بدون بناء Setup.

## هوية موحدة وقابلة لإعادة الاستخدام

- تبقى هوية الناشر **SoftRyva** ثابتة (الاسم، الطابع الداكن، ألوان الأزرق والبرتقالي).
- تختلف هوية المنتج (اسم **ImageFlow**، أيقونته، وصفه، إصدار النسخة).
- تُولَّد صور المعالج تلقائيًا من `installer/product.json` بواسطة `installer/shared/make_wizard_assets.py`.
- الملف المشترك هو `installer/shared/SoftRyva_Installer_Common.iss`؛ ملف إعدادات المنتج هو `installer/SoftRyva_ImageFlow.iss`.
- لأي برنامج آخر نستخدم معرّف AppId مختلفًا وثابتًا، حتى لا يزيل تثبيت أحد برامج SoftRyva برنامجًا آخر.
- لا يحتاج المستخدم إلى Python أو Inno Setup لتشغيل البرنامج المثبّت.

## ميزة Image Resizer الجديدة

في نافذة **Optimize** ستجد زر **IMAGE RESIZER** مباشرةً فوق زر **OPTIMIZE IMAGES**. ويمكن الوصول إليه أيضًا عبر بطاقة Image Resizer أو من Settings.

1. اضغط **IMAGE RESIZER**، ثم فعِّل **Enable image resizing during optimization**.
2. اختر **Pixels** إذا أردت عرضًا أو ارتفاعًا محددًا، أو **Percent** إذا أردت نسبة تصغير (مثل `50` لنصف الطول والعرض).
3. خيار **Keep original aspect ratio** مفعل افتراضيًا. عند وضع عرض فقط، يحسب البرنامج الارتفاع تلقائيًا؛ وعند وضع ارتفاع فقط، يحسب العرض. إذا أدخلت العرض والارتفاع معًا، فهما **الحد الأقصى لمساحة الصورة** دون تشويه. إذا ألغيت الخيار، يجب إدخال البعدين، وقد تتمدد الصورة.
4. **Allow enlarging smaller images** غير مفعّل افتراضيًا حتى لا تكبر الصور الصغيرة دون قصد. التكبير لا يضيف تفاصيل جديدة.
5. اضغط **APPLY RESIZE**، ثم اختر صورة أو صورًا واضغط **OPTIMIZE IMAGES**.
6. ستظهر رسالة النجاح ومسار الحفظ وأبعاد الصورة قبل التغيير وبعده (إن تغيرت)، مع **OPEN FOLDER** و**SAVE AS…**.

مثال: الصورة 3840 × 2160 عند اختيار `Percent = 50` تصبح 1920 × 1080. في المعالجة الجماعية، يُحافظ على نسبة أبعاد كل صورة بشكل مستقل عند تفعيل القفل.

## تشغيل البرنامج على Windows

1. ثبّت Python 3.10 أو أحدث من https://www.python.org/downloads/windows/ مع اختيار **Add Python to PATH**.
2. فك ملف ZIP في **مجلد جديد** ولا تستبدل ملفات النسخة القديمة أثناء تشغيلها.
3. افتح `START_WINDOWS.bat`. يحتاج التحميل الأول للمكتبات إلى الإنترنت، ثم تعمل المعالجة دون اتصال.
4. انزل بشريط التمرير في اليمين للوصول إلى البطاقات الأخرى عند استخدام شاشة صغيرة.
5. الصور محفوظة افتراضيًا في `Pictures\ImageFlow\Output`. لا يُعدِّل البرنامج الصور الأصلية ولا يستبدل الملفات الناتجة سابقًا.

**ملحوظة الترقية:** يحتفظ الإصدار الجديد بسجل History وإعدادات النسخة V0.2.0 لأنهما في مجلد البيانات المحلي نفسه؛ وميزة Resize **متوقفة افتراضيًا** حتى لا يتغير سلوك الضغط السابق دون موافقتك.

## الاختبارات

شغّل `python -m unittest discover -s tests -v` من مجلد المشروع. يتضمن المشروع اختبارات الرجوع لخصائص V0.2 واختبارات جديدة للأبعاد والنسب والشفافية واتجاه EXIF والمعالجة الجماعية والحفاظ على الملفات الأصلية.

لإنشاء ملف EXE على Windows، افتح `BUILD_WINDOWS_EXE.bat`. **ملف EXE لم يُبنَ أو يُختبر على Windows داخل بيئة التطوير الحالية**؛ لذا نحتاج اختبار جهازك قبل إعداد Setup والنشر في GitHub.

## توضيحات مهنية

- ميزة Smart Compression ليست ذكاءً اصطناعيًا، بل تجربة خيارات تشفير مختلفة وتقييم تقريبي للجودة.
- PNG يُحفظ بلا فقد بيانات البكسل *إذا لم تُغيّر الأبعاد*؛ أما تغيير الأبعاد فيعيد حساب البكسلات. JPEG وWebP قد يتسببان في فقد بعض التفاصيل.
- البرنامج محلي دون رفع صور إلى الإنترنت، ودون GPU أو تحديثات تلقائية في هذه النسخة.
- الاحتفاظ ببيانات EXIF/ICC اختياري وبأفضل جهد، وتُضبط بيانات الاتجاه والأبعاد حين تتوفر.
- لا نعلن V1.0 ولا نُنشر Setup نهائيًا قبل التجربة الواقعية على Windows.

## الملفات الأساسية

- `core.py`: محرك الضغط والتحويل وإعادة التحجيم.
- `imageflow.py`: الواجهة، إعدادات Resize، العمل الجماعي، السجل.
- `assets/`: أيقونة مؤقتة نولّدها من الشيفرة للمراجعة، وليست الشعار النهائي المعتمد.
- `tests/`: الاختبارات.
- `docs/`: لقطات شاشة فعلية من اختبارات الواجهة.
- `START_WINDOWS.bat`: تشغيل البرنامج.
- `BUILD_WINDOWS_EXE.bat`: إنشاء EXE على Windows.
